Keys and shortcuts

Double-click empty spaceNew note
Ctrl + VPaste a screenshot (text becomes a note)
Drag empty space, or Space + dragMove around
Scroll wheelZoom toward the cursor
Shift + dragSelect several things
PenDraw. Eraser end or side button erases
DDraw with the mouse (right-drag erases)
F  /  0Fit everything  /  100%
Ctrl + Z  /  Ctrl + YUndo  /  redo
DeleteDelete the selection
Ctrl + DDuplicate
Ctrl + FSearch notes
[  /  ]Send to back  /  bring to front
Arrow keysNudge (Shift for bigger steps)
